# Configuration contracts

Versioned, lightweight, machine-readable schemas, module manifests, fixed
graphs, frozen CPU thresholds, and compact CPU/GPU acceptance descriptors live
here. Generated run state and secrets do not.

`module_manifest.schema.json` is the canonical syntax for neural-module
manifests. `modules/` contains the five FOUNDATION_0 synthetic manifests and
`graphs/` contains the fixed candidate/extension graphs. These are research
test modules, not production cognitive modules.
