# Roadmap

Status: 25 October 2026. This publication preserves Foundation and records a new
research direction. It does not start a cognitive implementation or training run.

| Stage | Status | Completion evidence |
| --- | --- | --- |
| Bounded Foundation CPU | Historically accepted, CPU-01…15 PASS | Original contracts/source/acceptance reports retained; present smoke checks are a smaller verification. |
| Bounded Foundation GPU | Historically accepted on original target, G-01…15 PASS | Original host-bound evidence remains separate; clean source release does not repeat GPU qualification. |
| M1 event-understanding programme | Research archived, NOT_FROZEN; external project continues | [Repository](https://github.com/XRedMzK/M1-Event-Understanding) and [snapshot](https://github.com/XRedMzK/M1-Event-Understanding/releases/tag/research-snapshot-20261024). Not an active Alice dependency. |
| Clean Alice source / owner direction | This publication | Audited Foundation/common source, scoped tests, explicit implementation boundaries. |
| Collab candidate research | Future | Compare reusable functions against a bounded question, license/resource/interface constraints and meaningful controls before selecting mechanisms. |
| Neural memory and Memory Bridge | Future, mechanisms unselected | First agree observable acquisition/retrieval/persistence behavior and state ownership; implementation and learning require a separately scoped task. |
| Frozen Qwen integration | Future | Demonstrate language/response interfaces, frozen parameters, replaceability and causal effect of admitted memory information. |
| ComfyUI custom nodes / API | Future, external UI selected | Integrate a separately owned state/runtime; show UI restart does not erase memory. Telegram/Discord/CLI follow later. |
| Additional cognitive functions | Future, unselected | Define their own behavior/integration evidence; verify any memory migration rather than promising weight compatibility. |

The immediate research priority is to choose a small, testable functional question
for memory and Bridge design. There is no automatic M2 implementation, memory
training, Qwen fine-tuning or architecture experiment in this roadmap.
