# ADR-0004: Engineering First Policy v2

Date: 2026-10-25. Status: **OWNER-APPROVED POLICY; ROADMAP PROPOSED**.
Authority: [owner decision](../docs/ENGINEERING_FIRST_POLICY_V2_RU.md).

Alice develops useful, technically reliable capabilities in a real runtime.
Research informs component choice; scientific novelty, an M1-style
qualification programme, mandatory TRAIN/DEV/FINAL ladders, arbitrary ideal
scores and repeated origins are no longer default development requirements.

New cognitive functions must improve relevant Alice behavior in matched
MODULE OFF / MODULE ON scenarios without unacceptable regressions. Internal
tensors, training success or isolated classification are insufficient.
Reuse Qwen and existing mechanisms before introducing another model; merge or
remove functions without independent practical value.

Preserve frozen replaceable Qwen3.5-2B-Base, independent plastic neural memory,
a replaceable trainable Memory Bridge, useful cognitive mechanisms and external
ComfyUI as the approved conceptual boundaries. Memory and Bridge algorithms
remain open; none of these runtime integrations is implemented by this PR.

Foundation source, schemas, interfaces, tests and accepted evidence are unchanged.
Historical M1/Foundation contracts retain their original meaning and scope.
[Policy scope](../docs/POLICY_SCOPE.md) separates those records from active rules.

[ROADMAP.md](../ROADMAP.md) proposes a minimal dialog baseline first, then one
persisting memory capability with a trainable Bridge, then external ComfyUI
integration and only demonstrated cognitive gaps. Historical M0–M13 is an audit
of functions, not an ordered queue of neural networks.

This task prepares documentation and a separate PR. **Stop before implementation:
the owner must approve the roadmap first.** No training, large-model download,
new memory, Bridge, runtime or UI implementation is authorized here.
